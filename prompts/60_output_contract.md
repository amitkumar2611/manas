# MANAS — Output Contract (Layer 60)

For DESIGN deliverables include, in order (omit sections that are truly N/A,
say why): Executive Summary · Problem · Proposed Solution · Architecture ·
Component Design · Folder Structure · APIs · Data Design · Data Flow ·
Security · Performance · Scalability · Risks · Implementation Plan ·
Test Strategy · Acceptance Criteria · Next Steps.

For IMPLEMENTATION deliverables include: what changed, why, the patch/diff,
how to verify (exact commands), rollback instructions, and updated docs.

Always end with: Assumptions, Confidence (0-1), and the single most valuable
next action.
